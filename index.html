CSCE 242 – Web Applications

Author: Dmitriy Ignatov

This course teaches modern web development starting with pure HTML and CSS. Then progress into JavaScript, React, Node.js, Express, and MongoDB. Over the semester we will build a complete client-server application step by step. All work is version-controlled with Git and published live on GitHub Pages.
